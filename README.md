# Бот для учёбы: задания, дедлайны, напоминания

Пишешь боту обычным текстом: «сделать код в коллабе до конца октября, заметка: графики».
ИИ (Groq) вытаскивает задание, дату и заметку, бот сохраняет их в Supabase и каждое утро напоминает.

## Где что лежит (и что менять)

| Хочу изменить | Файл |
|---|---|
| За сколько дней напоминать, часовой пояс, границы 🔴🟡🟢, ИИ-модель | `config.py` |
| Время напоминаний (сейчас 9:00) | `vercel.json`, поле `schedule`. Время там в UTC: `0 4 * * *` = 9:00 по Астане/Алматы |
| Как ИИ понимает текст | `ai.py`, переменная `PROMPT` |
| Внешний вид сообщений, эмодзи, подписи кнопок | `view.py` |
| Новые команды и кнопки | `handlers.py` (+ строка в `COMMANDS` в `core.py`) |
| Логика напоминаний | `reminders.py` |
| Запросы к базе | `db.py` |
| Новые поля в таблице (например «предмет») | `schema.sql` + `db.py` + `view.py` |

Чтобы попросить у ИИ изменение, скажи, что хочешь, и приложи нужный файл.

## Шаг 1. Ключи и сервисы

1. **Токен бота**: в Telegram напиши @BotFather → `/newbot` → скопируй токен → `BOT_TOKEN`.
2. **Твой ID**: напиши @userinfobot, он пришлёт число → `OWNER_ID`. Бот отвечает только тебе.
3. **Groq**: твой ключ с console.groq.com → `GROQ_API_KEY`.
4. **Supabase**: лучше создай **новый проект**, чтобы не смешивать с другим (на бесплатном тарифе их два).
   - SQL Editor → New query → вставь содержимое `schema.sql` → Run.
   - Project Settings → API: **Project URL** → `SUPABASE_URL`, секретный ключ (`secret` или `service_role`) → `SUPABASE_KEY`.
   - Этот ключ даёт полный доступ к базе: только в `.env` и Vercel, никогда в публичный код.
5. **Две случайные строки** для `WEBHOOK_SECRET` и `CRON_SECRET`:
   `python -c "import secrets; print(secrets.token_urlsafe(24))"` (запусти два раза).

## Шаг 2. Проверка на своём ПК

```
pip install -r requirements.txt
copy .env.example .env      (на Mac/Linux: cp .env.example .env)
```
Заполни `.env`, затем `python run_local.py`. Напиши боту задачу, потом `/tasks` и `/check`.

## Шаг 3. Деплой на Vercel

1. Залей папку в GitHub (`.env` в репозиторий не попадёт, он в `.gitignore`).
2. vercel.com/new → выбери репозиторий → до нажатия Deploy открой **Environment Variables** и добавь 7 переменных из `.env`.
3. Deploy. Скопируй адрес вида `https://имя.vercel.app`.
4. На ПК, при заполненном `.env`, один раз запусти:
   `python setup_telegram.py https://имя.vercel.app`
5. Напиши боту. В Vercel → Settings → Cron Jobs должна быть задача `/api/cron`.

После `run_local.py` вебхук отключается: чтобы вернуть бота на Vercel, снова запусти `setup_telegram.py`.

## Важно про напоминания

На бесплатном тарифе Vercel cron запускается раз в сутки и **в любую минуту выбранного часа**, то есть напоминание придёт между 9:00 и 9:59. Точнее на бесплатном тарифе не выйдет. Если нужна точная минута, можно вызывать `/api/cron` через бесплатный внешний планировщик (например cron-job.org) с заголовком `Authorization: Bearer <CRON_SECRET>`.
